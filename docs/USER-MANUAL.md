# 📱 そろばん練習サービス ユーザーマニュアル

お子さまのそろばん練習をサポートするWebサービスです。
スマホからワンタッチで問題用紙の印刷や音声再生ができます。

---

## 🎯 できること

### 1. 📄 問題用紙の印刷
- **アバカスサーキット**: F0/F1/F2プリント、過去問題
- **そろばんコンクール**: 2015-2024年の過去問
- **あんざんコンクール**: 2022-2024年の問題

### 2. 🔊 読み上げ音声の再生
- 読み上げ算・よみあんの練習音声
- 30秒/35秒/40秒/50秒問題に対応

### 3. ⭐ お気に入り機能
- よく使う問題を保存
- ワンタップですぐアクセス

### 4. 📜 履歴機能
- 最近使った問題を自動記録
- 「前に使ったあの問題」がすぐ見つかる

---

## 📲 スマホへのインストール

### iPhoneの場合

1. Safariでサービスを開く
2. 画面下の **共有ボタン** (□↑) をタップ
3. **「ホーム画面に追加」** を選択
4. **「追加」** をタップ

→ ホーム画面にアイコンが追加されます！

### Androidの場合

1. Chromeでサービスを開く
2. 画面右上の **メニュー** (⋮) をタップ
3. **「ホーム画面に追加」** を選択
4. **「追加」** をタップ

---

## 🔧 使い方

### 問題用紙を印刷する

1. カテゴリを選ぶ（アバカスサーキット、そろばんコンクール等）
2. 問題のボタンをタップ
3. PDFが開く
4. 印刷ボタンをタップ

### 音声を再生する

1. 「読み上げ算・よみあん」セクションへ
2. 聴きたい問題をタップ
3. 音声が再生される

### お気に入りに追加する

1. 問題ボタンの ⭐ アイコンをタップ
2. お気に入りセクションに追加される
3. 解除は同じアイコンを再度タップ

## ❓ よくある質問

### Q: PDFが開かない
**A:** ポップアップがブロックされている可能性があります。
- iPhone: 設定 → Safari → ポップアップブロック をオフ
- Android: Chrome設定 → サイトの設定 → ポップアップ を許可

### Q: 音声が再生されない
**A:** 以下をお試しください：
- 音量を確認
- サイレントモードを解除
- ブラウザを再起動

### Q: オフラインで使える？
**A:** 一度アクセスしたページはオフラインでも閲覧可能です。
ただし、PDFの表示と音声再生にはインターネット接続が必要です。

### Q: お気に入りが消えた
**A:** ブラウザのデータを消去すると、お気に入りと履歴もリセットされます。
別のブラウザでは共有されません。
